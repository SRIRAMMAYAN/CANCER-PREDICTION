# Cancer Prediction System

This is a cancer prediction demo app using a Random Forest classifier and Streamlit.

## Run the app

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Start Streamlit:
   ```bash
   streamlit run "cancer prediction.py"
   ```

If you prefer, you can rename `cancer prediction.py` to `app.py` and run:
```bash
streamlit run app.py
```
